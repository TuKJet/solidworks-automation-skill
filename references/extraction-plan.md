# 独立出图 Skill 提取计划

1. 在 vm-sw-3d-2d 分支保留原出图、审查、会话、清单、批次和账本代码及其回归测试；原完整工具包保留在 vm-sw-automation-skill。
2. 移除建模、仿真、桌面 UI、通用 MCP 及旧安装入口；账本脱离桌面模块，只迁移既有实现和两个小型辅助函数。
3. 新增独立 CLI，读取真实模型包围盒/配置，复用原生出图和审查；数据写到工程 agent 子目录，失败及待审不标为生产可用。
4. 新增固定 GitHub 分支安装更新器；拒绝覆盖、脏目录和非快进更新；验证安装、升级和回滚。
5. 使用继承的回归测试、CLI 集成测试、独立临时目录安装测试验证；真实 SolidWorks 若被其他作业占用，不抢占资源。
